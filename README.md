# InGaAs-DG-MOSFET-Analysis

**Overview**
This project focuses on the simulation and performance analysis of Double Gate (DG) MOSFETs using Synopsys Sentaurus TCAD. Silicon and InGaAs channel materials are compared based on electrical characteristics and device performance.


**Technologies Used**
Synopsys Sentaurus TCAD
SDE
SDEVICE
SVisual


**Features**
DG MOSFET structure design
IDS–VGS characteristic analysis
Threshold voltage extraction
Subthreshold swing analysis
Silicon vs InGaAs comparison
Oxide thickness variation study


**Results**
InGaAs shows higher ON current
Improved switching characteristics
Better electrostatic control compared to Silicon


**Applications**
Nanoelectronics
VLSI Design
Advanced CMOS Devices
